# Markdown View

Opens `.md` files directly as a rendered, single-pane reading view — the file tab *is*
the preview, no second pane.

- Themed entirely from VS Code CSS variables, so it follows whatever theme is active
  (dark stays dark).
- Live re-render while you edit the source side by side, preserving scroll position.
- Syntax-highlighted code blocks, tables, relative images, working heading anchors.
- Read-only by design: editing happens in the text editor. Click the `</>` button in the
  editor title bar (or run **Markdown View: Edit Source**) to switch.

No telemetry, no network access, no paid tier.
